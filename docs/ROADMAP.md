# Дорожная карта

Каждый этап сохраняет формат корпусов и автономную GitHub Pages-версию.

1. ✅ **Переносимая основа.** Next.js, кроссплатформенные команды и CI.
2. ✅ **Локальный API и контейнеры.** FastAPI health/capabilities, OpenAPI, Next.js standalone и единый nginx gateway через Docker Compose.
3. **Серверное рабочее пространство.** PostgreSQL, долговременные проекты, очередь и worker.
4. **PDF/OCR.** Извлечение с обязательной пользовательской проверкой.
5. **Автоматические ударения.** Локальные объяснимые подсказки с ручным контролем.
6. **Метрический анализ.** Гипотезы метра и диагностика.
7. **Локальная языковая модель.** Опциональная помощь без облачного API.
8. **Многопользовательская работа.** Учётные записи и доступ.
9. **Выпуски Windows/macOS/Linux.** Проверенные `amd64`/`arm64` пакеты и обновления.

На текущем этапе документы всё ещё находятся только в IndexedDB. API не принимает тексты и не реализует PDF/OCR, ударения, метр, локальную модель или фоновые задания: соответствующие capabilities честно равны `false`. Внешних API и телеметрии нет.

Реестр правил R001–R010 остаётся фундаментом будущего анализатора; R011–R017 планируются и не выдаются за автоматизированные.
