# Дорожная карта

Этапы перечислены в предполагаемом порядке. Каждый этап должен сохранять совместимость формата корпусов и возможность работы облегчённой версии GitHub Pages.

1. **Переносимая основа.** Стандартный Next.js, кроссплатформенные npm-команды, CI на Windows/macOS/Linux, документация режимов.
2. **Локальный API и контейнеры.** Проектирование API и воспроизводимого локального/self-hosted-развёртывания.
3. **Серверное рабочее пространство.** Долговременное хранение проектов, очередь заданий и worker.
4. **PDF/OCR.** Извлечение текста с обязательной проверкой и исправлением результата пользователем.
5. **Автоматические ударения.** Локальные подсказки ударений без потери ручного контроля.
6. **Метрический анализ.** Автоматические гипотезы метра и диагностические объяснения.
7. **Локальная языковая модель.** Опциональная локальная помощь без обязательного внешнего API.
8. **Многопользовательская работа.** Учётные записи, разграничение доступа и совместные серверные проекты.
9. **Выпуск для Windows/macOS/Linux.** Проверенные пакеты для `amd64` и `arm64`, документация установки и обновления.

PDF/OCR, backend, контейнеры, базы данных и модели относятся к последующим этапам и не входят в переносимую основу.
