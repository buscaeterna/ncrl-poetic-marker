# Автоматические ударения: локальная установка и проверка

Функция доступна только в полном Docker-режиме. Она использует локальную CPU-модель Silero Stress 1.4; тексты не отправляются во внешние API, телеметрии нет. Модель предлагает разметку, но не заменяет филологическую проверку.

## Запуск и модель

На Windows/macOS установите Docker Desktop, на Linux — Docker Engine и Compose plugin. Выполните `docker compose up --build` и откройте <http://127.0.0.1:8080>. Откройте серверный проект, затем «Автоматические ударения».

Нажмите «Установить модель». UI показывает версию, размер, состояние, прогресс и SHA-256; из сети загружается только доверенный wheel, текст остаётся на компьютере. Для полностью офлайн-машины заранее скачайте файл с именем `silero_stress-1.4-py3-none-any.whl`, перенесите его и выберите «Офлайн-импорт». Произвольные URL и файлы с другим именем, размером или SHA-256 отклоняются. Доступны повторная проверка и удаление.

## Пакетный анализ и проверка

Выберите текущее, несколько или все произведения. Диалог показывает число строк, очередь, прогресс и отмену. После анализа отфильтруйте сомнительные строки, сравните оригинал и предложение, выберите вариант омографа, примите слово/строку, отклоните или исправьте вручную. Массовое принятие показывает порог и количество строк и требует подтверждения. Изменённая строка делает старое предложение устаревшим. Непринятые предложения не попадают в TXT/HTML.

`ё` считается ударной без лишнего `` ` ``. Имена, OCR-ошибки, неизвестные слова, сокращения и дореформенная орфография требуют особого внимания. Silero не даёт калиброванной вероятности: отображаемые 0,80/0,65 — эвристика; омограф всегда требует проверки.

## Данные и обслуживание

Для резервной копии остановите stack и сохраните volumes `ncrl_data`, `ncrl_files`, `ncrl_models`. Обновление: `docker compose pull && docker compose up --build`; не используйте `down -v`. Полное удаление: `docker compose down -v`. Требуется ориентировочно 1 GiB RAM; модель занимает около 105 MiB в `ncrl_models`, дополнительно нужны образы Docker и данные проектов.
