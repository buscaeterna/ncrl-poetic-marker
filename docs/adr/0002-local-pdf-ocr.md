# ADR 0002: локальный PDF/OCR и файловое хранилище

**Статус:** принято, 2026-08-04.

PDF и PNG-preview хранятся под серверными ключами в Docker volume `ncrl_files`; PostgreSQL хранит документы, страницы, происхождение, исправления и ревизии. PyMuPDF извлекает текст и рендерит страницы, Tesseract `rus+eng` распознаёт страницы с плохим слоем. Всё работает локально на CPU amd64/arm64. Внешняя команда запускается без shell.

Worker `pdf_extract` принимает решение отдельно по странице и фиксирует прогресс. Job содержит идентификаторы и статистику, не PDF/полный текст. Импорт блокируется до подтверждения. Данные переживают restart, но резервировать БД и volume нужно согласованно. Образ больше. Лицензии: Tesseract Apache-2.0; PyMuPDF/MuPDF AGPL-3.0.
