# ADR 0003: локальный движок словесных ударений

Статус: **принято** (2026-08-04).

## Выбор и аудит артефакта

Сравнивались RUAccent и официальный [Silero Stress](https://github.com/snakers4/silero-stress). Выбран Silero Stress 1.4: контекстная модель различает омографы, работает локально на CPU и не содержит телеметрии или сетевого кода при inference. Зафиксирован исходный commit `76706c123dc9ac0ca0b2b428d132a71c6cc4ff36` и неизменяемый PyPI wheel:

* URL: `https://files.pythonhosted.org/packages/ba/72/5edf26c74a8d48640108976db5bc3e9e59722b63ccaa36b21894bf79ad77/silero_stress-1.4-py3-none-any.whl`;
* размер: 38 587 594 байта (36,8 MiB);
* SHA-256: `c772725dc03c647e2b33961280dc35f41b7f43ac0861575884fea0c2a6cb8ae2`;
* единственная лицензия distribution: MIT (`silero_stress-1.4.dist-info/licenses/LICENSE`).

Wheel просмотрен целиком: Python-код, русский `accentor.pt` (53 792 977 байт), украинский/белорусский accentor, словари других языков, METADATA/RECORD и MIT LICENSE. Отдельных лицензий или сторонних notices для весов и встроенных словарей нет; следовательно издатель распространяет весь wheel, включая веса, homograph dictionary и vocabularies, под приложенной MIT-лицензией. Код репозитория имеет тот же MIT LICENSE. RUAccent не выбран, поскольку один проверенный движок достаточен, а Silero предоставляет модель и словари одним версионированным лицензированным артефактом.

## Установка и платформы

Trusted manifest находится в коде; API не принимает URL. Явная загрузка или офлайн-импорт пишет `.part`, проверяет имя, точный размер и SHA-256, безопасно распаковывает во staging и атомарно переносит в `ncrl_models`. Wheel сохраняется рядом с распаковкой для повторной проверки. Повреждённая/неполная модель имеет состояние `error`, а `.part` удаляется. Удаление и verify доступны отдельно.

PyTorch 2.8.0 устанавливается из официального CPU-only index. Python wheel Silero platform-independent; операции модели исполняются PyTorch CPU. Образы собираются для `linux/amd64` и `linux/arm64`; GPU не требуется. Ориентир: 1 GiB RAM, около 105 MiB в `ncrl_models` (wheel плюс распакованные файлы); PyTorch увеличивает backend image. Реальный inference smoke выполняется один раз на Linux amd64; arm64 проверяется сборкой образа, поскольку GitHub-hosted arm64 runner в проекте отсутствует.

## Формат и качество

Provider вызывается для полного контекста строки. Пунктуация и пробелы берутся только из исходника; ответ модели сообщает позиции гласных. Имеющиеся обратные апострофы неизменяемы. `ё` сама кодирует ударение и дополнительный апостроф не получает. Встроенные списки `homodict`/`yohomodict` дают варианты омографов для ручного выбора.

Silero не выдаёт калиброванную вероятность. UI confidence — явно документированная эвристика: 0,80 для результата модели, 0,65 для омографа, 1,00 для существующей разметки/`ё`; неизвестный результат получает 0. Омографы всегда сомнительны независимо от score. Модель предлагает, но не заменяет филологическую проверку.
