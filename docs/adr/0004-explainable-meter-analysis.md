# ADR 0004: локальный объяснимый метрический анализ

## Статус

Принято для первого подэтапа этапа 6 (2026-08-10).

## Источники и границы

Решение основано на реестре `app/annotation-rules.json` (R001–R017),
`annotation/CONFIRMED_RULES.md`, `SOURCE_PRECEDENCE.md`, `OPEN_QUESTIONS.md` и
[терминологическом указателе НКРЯ](https://ruscorpora.ru/page/corpus-poetic-index/).
Отсутствующая основная PDF-инструкция не реконструируется. Неопределённый случай
получает `insufficient`/`manual_review`.

## Решение

Анализатор читает только `CorpusLine.text`: `ё` и обратный апостроф после гласной
являются подтверждённым ударением. Непринятый `stressSuggestion` игнорируется.
Сначала проверяются шаблоны Х, Я, Д, Аф, Ан, затем интервалы Дк (1–2 безударных
слога), Тк (0–3), и лишь затем Ак. Вл не назначается. Ранжирование лексикографическое
по R011, без псевдовероятности; сохраняются наблюдаемые пропуски икта, ударения на
слабом месте и неизвестные позиции.

Предложение подписано SHA-256 текста и версией алгоритма. Worker дважды проверяет
revision, отменяется между строками и атомарно сохраняет предложения в workspace.
Применение строки — явное действие. Автоматическое применение метаданных и
структурные решения R016/R017 пока не формализованы и направляются на ручную
проверку, не меняющую структуру исходника.

## Последствия

Результат воспроизводим и работает без сети, LLM и словаря. Цена — обязательная
ручная проверка недостаточно акцентированных строк, специальных исторических форм,
логаэдов, гекзаметра/пентаметра, сложной полиметрии, рифмы и верлибра.

Сводка исключает `stale`/`rejected`, несовпадающие SHA-256 и версии анализатора.
Контекст строится только по независимым `exact`/`probable` строкам. Числовой порог
для гетерометрии/полиметрии не вводится; наблюдаемое распределение передаётся
эксперту. Порядок клаузул сохраняется, но неподтверждённый формат цикла не
синтезируется в `@формула`.
